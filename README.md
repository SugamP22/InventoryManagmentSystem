📦 Inventory Management System

Hi, this is an Android-based Inventory Management System built to help small and medium-sized businesses manage their stock efficiently.
The goal of this project was to create a simple, fast, and offline-first solution that feels easy to use while still being powerful under the hood.

This app allows users to add, edit, and track inventory items, receive low-stock alerts, and manage data locally using a reliable database.
It was built with a strong focus on performance, usability, and clean architecture.

✨ What the App Can Do

🌐 Switch between two languages seamlessly

🗃️ Add, update, and view inventory items with detailed information

🔔 Automatically detect low-stock items (quantity below 5)

⚡ Refresh stock notifications every 5 seconds using Java threads

💾 Store all data locally with Room for offline reliability

🧠 Behind the Scenes

The application uses Room Database to ensure fast and secure local data storage.
A background Java thread continuously monitors inventory levels and updates notifications in real time, allowing the app to stay responsive without manual refresh.
